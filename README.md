## Quick Start — Run All Analyzers
```bash
# Clone all repos
for repo in blackrock-opportunity-analyzer palantir-opportunity-analyzer paypal-fintech-analyzer \
            wef-global-opportunity-analyzer who-global-health-analyzer us-government-opportunity-analyzer \
            airbnb-opportunity-analyzer real-estate-tokenization; do
    git clone https://github.com/BlockchainNooberz/$repo
done

# Install dependencies
pip install pandas numpy requests yfinance rich python-dotenv

# Run any analyzer
python blackrock-opportunity-analyzer/blackrock_analyzer.py
python palantir-opportunity-analyzer/palantir_analyzer.py
# ... etc
```
